# dsh-w-deslop

## 官方 Harness 兼容

`0.1.1` 已适配官方 Windows Harness `0.2.0-rc.2`。兼容官方严格 RPC 编解码器及独立 UI slots 服务，设置中的文本扫描可用。

官方桌面版使用独立的 `desktop` profile，旧 `web` profile 的插件不会自动迁入。可在官方「添加插件」填写本包 `.tgz` 的绝对路径，或通过 W 管理器拖入本包；安装后重启 Harness。以下 `--profile web` 命令用于旧版 Web 环境。

DeepSeek Harness 的「去 AI 味」插件，是 `dsh-w-noval-write`（小说写作）的配套插件。

规则综合自几个公开的去 AI 味 skill：网文专用的 story-deslop（oh-story）、Humanizer-zh、de-ai-flavor。

## 什么时候生效

同时满足下面三个条件才生效，缺一个就完全不起作用：

1. 已安装并启用 `dsh-w-noval-write`；
2. 当前对话在右侧「小说写作」工作台绑定了一本书，并用 `/write` 建立了写作任务；
3. 本插件设置里的「启用去AI味」是打开的（默认打开）。

其他对话、没有 `/write` 的对话、小说插件被停用时，不注入规则，`/deslop` 命令不出现，扫描工具也会拒绝执行。小说插件之后再启用，会自动联动，不需要重启。

## 功能

- **写作规则**：在小说插件的「绑定小说」提示段后面，追加一段去 AI 味写作规则。内容包括视角与解释腔、章尾升华、「不是A，而是B」等套路句式、套词清单、句长节奏、对话与场面。
- **保存前自查**（默认开）：让模型在调用 `novel_save_chapter` 保存章节前，先用 `deslop_scan` 扫一遍正文，处理完「必改」项再保存。
- **`deslop_scan` 工具**：确定性扫描，不调用模型。返回带行号的「必改 / 复核」清单和节奏统计。可以传正文 `text`，也可以传小说文件夹里的章节文件名 `filename`。
- **`/deslop` 命令**：
  - `/deslop`：对最近一章去 AI 味；
  - `/deslop 第3章_入门.md`：对指定章节去 AI 味；
  - `/deslop status`：查看当前是否生效和当前设置。

  修改后由模型用 `novel_save_chapter` 写回同一个文件。小说插件每次保存都会存版本历史，改坏了可以在工作台里恢复。
- **设置面板**：「插件」列表里 dsh-w-deslop 的齿轮。可以开关插件、切换严格模式、开关保存前自查，编辑自定义禁用词和白名单，查看注入的完整规则。还可以粘贴一段文字试扫，只在本地扫描，不发给模型。

## 扫描规则

「必改」项在小说里几乎总是减分，建议全部处理：

- 「不是A，而是B」句式；
- AI 高频套词：仿佛、一丝、一抹、眼中闪过、嘴角勾起、深吸一口气、不禁、心中一凛、不容置疑等；
- 网文陈词：恐怖如斯、全场哗然、倒吸一口凉气等；
- 「，带着一丝……」万能状语，「声音不大，却……」「语气平静得……」；
- 上帝视角和解释腔：殊不知、他不知道的是、冥冥之中、之所以……是因为、这意味着（只查叙述，不查对话）；
- 章尾总结、升华、预告（只对三段以上的完整章节检查）；
- 严格模式下，另外检查破折号和省略号造停顿。

「复核」项要结合语境判断，有功能的写法可以保留：

- 告知式情绪：他感到、她意识到、显得；
- 总结、升华句；
- 论文腔连接词；
- 三连排比；
- 弱化副词过密：缓缓、微微、轻轻、淡淡合计每千字超过 3 个；
- 电报体：叙述句平均不到 12 字，且短句过半。

扫描器只报告问题，不判断文字「是不是 AI 写的」。白名单里的词永远不报。

## 数据

设置保存在 profile 下的 `.dsh-w-deslop.json`。插件不写 `cordis.patch.yml`：改写那个文件会让 Harness 热重载插件树，并销毁正在打开的会话。

## 安装

```powershell
pnpm pack
node "<桌面版安装目录>\DeepSeek-Harness-Desktop\resources\runtime\node_modules\@deepseek-ai\dsh\lib\bin.js" plugin --profile web add ./dsh-w-deslop-0.1.1.tgz
```

重启桌面版后生效。卸载：

```powershell
dsh plugin --profile web remove dsh-w-deslop
```
