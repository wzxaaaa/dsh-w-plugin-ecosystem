# dsh-w-api-key-switcher

DeepSeek Harness 模型提供商 API Key 多配置切换器。

## 功能

- 在「设置 → 模型」的每个已配置提供商卡片中增加“API 密钥配置”；
- 同一提供商可保存最多 50 组 API Key；
- 每组密钥使用名称标识，并可一键切换；
- 编辑已保存配置时可修改名称，或输入新 API Key 替换原密钥；留空则保留原密钥；
- 替换当前正在使用的密钥时，同步更新活动凭据，下一次模型请求即生效；
- 切换后从下一次模型请求起即时生效，无需重启 DSH；
- 页面永远不会读取或回显保存的密钥明文；
- 正在使用的配置会被识别并标记，必须先切换才能删除；
- 如果同名环境变量从启动环境注入并覆盖本地凭据，插件会明确显示只读原因。

## 数据与安全

密钥保存在 Harness 官方 `ctx.credentials` 私密凭据存储中，不写入模型设置、插件目录或工作区。浏览器只会收到配置名称和当前使用状态。

插件按提供商使用一个独立的私密 vault。切换时，将选中的密钥写入该提供商当前 `apiKeyEnv` 指向的凭据引用。Harness 在每次模型请求前重新解析该引用，因此切换立即影响下一次请求。

## 安装

```powershell
dsh plugin --profile web add ./dsh-w-api-key-switcher-0.1.4.tgz
```

安装后重启 DSH，打开「设置 → 模型」，展开任意已配置提供商卡片下方的“API 密钥”。点选一行即可切换；悬停行可编辑名称或替换密钥，也可删除（删除为行内二次确认）。编辑时不会回显旧密钥。

## 限制

- 当前支持最新版 Harness 的官方 `DeepSeek / deepseek-official` 卡片，以及 `llm-pi-ai` 中的内置和自定义提供商卡片；
- 启动环境变量优先级高于本地凭据。被环境变量覆盖时，必须先从启动脚本或系统环境中移除该变量，插件才能切换；
- 为防止误删后出现“仍在使用但列表已没有”的幽灵状态，当前正在使用的密钥不允许直接删除。
