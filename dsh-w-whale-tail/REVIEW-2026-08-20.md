# dsh-w-whale-tail Review 与续作记录（2026-08-20）

## 本次结论

原始 whale-tail 不是只差一点 UI：宿主端的 system prompt section 生命周期注册、模型工具 output 合约、客户端 selector hook 和若干状态/渲染细节都需要修正。除此之外，原先让 whale-tail 自己占据 `shell.overlay` 的悬浮卡片也不符合用户希望的“右侧 Sidebar”形态。

本次完成两层重构：

1. 修复 whale-tail 的宿主端、状态模块和客户端稳定性问题。
2. 将客户端改为 `dsh-w-right-sidebar` 的入口、工具卡片和功能页；Sidebar 的工具目录、返回和展开/收缩由独立宿主统一负责。

当前 whale-tail 版本为 **0.5.0**，配套的右侧 Sidebar 宿主为 **0.6.0**。本次没有执行 GitHub 推送。

## 已修复

### 宿主端与工具

- 将 `ctx.systemPrompt.section(...)` 放入正确的 `ctx.effect(...)` 生命周期。
- 为 `whale_remember` 和 `whale_lewdness` 补齐结构化 output schema 与模型可见 render 结果。
- `whale_lewdness` 严格要求 `value` / `delta` 二选一。
- 普通问候不再要求无意义的鲸鱼工具调用。
- Code Mode 下明确要求从 `run_code` 内通过 `tools.whale_*` 调用。
- 状态 map、空会话和持久化边界处理更安全。
- `whale_lewdness` 支持正负 `delta`，淫乱值下降时仍会经过 `0..100` clamp。
- system prompt 已明确下降条件：平静聊天、被拒绝、话题转为日常/严肃、道歉冷静、情绪疏离或长时间没有刺激时小幅下降；普通问候通常不变。

### 客户端

- `useSessions` 改为传入 selector，符合真实 Harness 的 selector hook 合约。
- 轮询加入请求序号和 session 校验，避免旧会话结果覆盖新会话。
- 静默刷新失败时保留已有状态。
- 心形 SVG 的 gradient/clip ID 改为实例级唯一。
- 恢复液面动画、接入中英文 locale，并在卸载时清理自有样式。
- 增加无会话、重置中和失败状态。
- 使用用户提供的蓝发鲸鱼娘主立绘，处理为透明 WebP；轻量副本内嵌 client bundle，避免安装后的静态资源路由差异导致图片空白。
- 增加呼吸漂浮、眨眼、腮红、表情气泡和状态动作：平静、开心、害羞、心动、冷静回落、担心。
- 淫乱值变化会触发短暂的跳动或回落动作，新记忆写入会触发开心反馈。

### 右侧 Sidebar 重构

- 移除 whale-tail 自己的独立 `shell.overlay` 面板和折叠按钮。
- 注册到 `right-sidebar.rail`，提供 `🐋` 功能入口。
- 注册到 `right-sidebar.card`，提供工具列表中的“鲸鱼娘”卡片，副标题为“鲸鱼娘状态与对话记忆”。
- 注册到 `right-sidebar.page`，提供展开后的鲸鱼功能页。
- 从收缩状态点击 `🐋` 时直接进入功能页，左上角按钮收起 Sidebar。
- 从工具列表卡片进入功能页时，左上角按钮返回工具列表。
- 依赖 `dsh-w-right-sidebar`，安装顺序为先宿主、后功能页。
