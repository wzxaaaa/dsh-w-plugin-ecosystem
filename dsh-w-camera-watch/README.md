# dsh-w-camera-watch

## 官方 Harness 兼容

`0.2.3` 已适配官方 Windows Harness `0.2.0-rc.2`。兼容官方当前会话选择，目标监督不会误绑定后台会话。摄像头截图已在官方 Host 中使用测试视频流验证；本机麦克风与 Windows 语音包仍依赖设备环境。

官方桌面版使用独立的 `desktop` profile，旧 `web` profile 的插件不会自动迁入。可在官方「添加插件」填写本包 `.tgz` 的绝对路径，或通过 W 管理器拖入本包；安装后重启 Harness。以下 `--profile web` 命令用于旧版 Web 环境。

让 DeepSeek Harness 中的模型直接调用浏览器摄像头截图，并在活动 Goal 中持续收音，将用户讲话自动转成真正的用户消息送入当前对话。适合监督学习、写作业、工作状态、动作与环境。

## 功能

- 注册模型工具 `camera_capture`：每次调用都会获取当前摄像头的一帧 JPEG 图片。
- 图片进入 Harness 的持久附件存储并成为工具结果，视觉模型能在下一步直接查看。
- 注入 Goal 使用提示：需要核实真实进度时可以反复截图，不能未调用就声称看见了用户。
- 在“设置 → 摄像头监督”中选择设备、查看实时预览、测试完整 Host 桥接链路。
- 默认记住“启动 DSH 时自动连接”，浏览器首次许可后无需每轮人工确认。
- 支持多个打开的 DSH 页面；当前可用页面会自动领取截图请求，首个成功结果生效。
- 默认开启“Goal 期间自动收音”：当前会话存在活动 Goal 时，Edge/Chrome 连续识别用户讲话。
- Windows 上默认调用系统自带的本地语音识别器和默认麦克风，不经过浏览器在线服务，因此不会再受 Web Speech `network` 错误影响。
- 只发送浏览器确认的最终识别段；相邻片段在短暂停顿后合并，并通过 Host `followup` 成为正式用户消息。
- Host 在入队前再次确认目标会话仍有活动 Goal，并用唯一 `speechId` 去重，旧页面不会把语音误投到普通对话。
- 可选择普通话、繁体中文、英语、日语或韩语识别，也可以随时停止或重新启动收音。

## 使用

1. 安装插件并重启 DSH。
2. 浏览器首次询问摄像头权限时选择允许；也可进入“设置 → 摄像头监督”点击“启动并授权”。
3. 确认页面显示“摄像头已连接”，点击“测试截图”检查画面。
4. 在对话中说“调用摄像头看看我现在在做什么”，模型会调用 `camera_capture`。
5. 创建监督学习 Goal 后，插件会自动启动麦克风；你在过程中说的话会转写并进入当前会话队列。

当前主模型必须声明图片输入能力。纯文本模型无法理解工具返回的真实图片，插件会明确要求切换视觉模型。

摄像头由承载 DSH Web GUI 的页面提供，因此页面必须保持打开，首次使用需要授予摄像头权限。默认“Windows 本地识别”直接使用系统默认麦克风和 Windows 已安装的语音识别语言，不需要浏览器麦克风权限；Windows 隐私设置仍需允许桌面应用访问麦克风。也可以手动选择“浏览器设备端识别”或“浏览器在线识别”，后者依赖浏览器厂商服务，受限网络下可能失败。

## 安装

```powershell
dsh plugin --profile web add .\dsh-w-camera-watch-0.2.3.tgz
```

安装后重启桌面版或重新启动当前 `dsh web` 服务。
